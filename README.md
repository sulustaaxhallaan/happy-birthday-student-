# С днём рождения, Дьулустаан! 🏀

Интерактивное поздравление для одногруппника с физкультурного: мультяшный именинник бросает мяч в кольцо, и каждое попадание открывает поздравление от группы.

- 5 бросков, каждый сложнее: короче прицел, кольцо поднимается, ездит и летает
- физика мяча: отскоки от кольца и щита, качающаяся сетка, конфетти
- табло попаданий и точности, «шкафчик» с открытыми поздравлениями
- управление мышью, пальцем или с клавиатуры (стрелки + пробел)

Одна HTML-страница без сборки: `index.html` + картинки в `img/`. Имя именинника и тексты поздравлений — в начале скрипта (`NAME`, `WISHES`).
